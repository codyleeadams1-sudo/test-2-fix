# Quick Menu (Fabric, Minecraft Java 26.3)

Press Right Shift in a world to open a menu of command buttons. It only sends normal
commands, so it works in singleplayer with cheats enabled or on your own server as op.

Build: push to GitHub (Actions builds it) or run `gradle build` with JDK 25 + Gradle 9.6.
Install: Fabric Loader 0.19.5+, Fabric API for 26.3, and this jar in %appdata%\.minecraft\mods
